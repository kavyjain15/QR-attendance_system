# QR Attendance System

A Python-based QR code attendance system designed to make attendance tracking faster and more organized.

## 🚀 Features

- Student login system
- QR code generation
- QR-based attendance
- Attendance record management
- Student database
- Attendance CSV records

## 🛠️ Technologies

- Python
- QR Codes
- CSV
- Local Database
